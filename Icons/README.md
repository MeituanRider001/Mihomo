# Icons

Bettbox 脚本使用的策略组图标，共 38 个 SVG，统一 144 × 144 画布。

- `svg/` —— 图标本体，脚本按文件名引用
- 来源：自 [MeituanRider001/Qure_Style_SVG](https://github.com/MeituanRider001/Qure_Style_SVG) 整理
- 引用格式：`https://fastly.jsdelivr.net/gh/MeituanRider001/Mihomo@main/Icons/svg/<图标名>.svg`

## 命名约定

- 地区旗帜使用 `下划线` 分隔：`Hong_Kong`、`United_States`
- 服务图标使用驼峰或原名：`AdBlock`、`Telegram`、`YouTube`
- 特殊对照：`Taiwan`（对应 TW 组）、`ChatGPT`（对应 AI 组）、`Round_Robin`（对应负载均衡组）、`Global`（对应 Other 组）
